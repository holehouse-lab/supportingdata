# Figure S13A — family-level tree (TFAP), copied as-is

`Supplemental_Fig_6a.pdf` is the published panel. The tree was built in R with taxize (`GetSppFamilies.R`); the mean TFAP per family (`MeanPerFamily_TFAP.csv`) and the family tree (`Families_tree_rearranged.nwk`) are in `../../../data/tree_of_life/`, and the result was drawn in iTOL and finished by hand.
These files are copied from the original Figure 2A analysis (now Figure 3A); the script is identical to `maintext_figures/figure_3/Figure_2A_just_analysis_no_notebook/GetSppFamilies.R`, and only its data paths have changed. They use the 2024 (pre-3.1.0) metapredict V3 proteome predictions.
See `maintext_figures/figure_3/Figure_2A_just_analysis_no_notebook/README.md` for the full workflow.
